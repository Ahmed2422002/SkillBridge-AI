# SkillBridge AI

منصة تعلم ذكية تساعد الطلاب على بناء مسار تعلم شخصي ومتابعة تقدمهم.

## الميزات
- تسجيل ودخول المستخدمين
- إنشاء خطط تعلم مخصصة
- استبيان لجمع بيانات المستخدم
- عرض محتوى تعليمي (فيديوهات، مقالات، روابط)
- متابعة التقدم ونسبة الإنجاز
- اختبارات قصيرة مع تصحيح تلقائي
- نظام مرشدين وحجز جلسات
- لوحة تحكم للمشرف

## التقنيات المستخدمة
- Python 3.14
- FastAPI
- SQLAlchemy
- SQLite
- JWT
- Pydantic

## طريقة التشغيل
bash
pip install -r requirements.txt
uvicorn app.main:app --reload
